# IoT Monitoring Dashboard

This project is a dashboard interface for monitoring IoT data in real time. The dashboard supports API monitoring, OTA updates, and other data visualizations.

## Features
- Real-time dashboard view
- API integration for data retrieval
- Over-The-Air (OTA) update support
